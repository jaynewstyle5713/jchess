# 03단계 검수: 순수 Java 기반 서버 체스 도메인 및 규칙 엔진 구현 (TDD)

## 검수 주체

- PM: Phase 1 및 CP-03 요구사항 충족 및 MVP 범위 규칙 완성도 확인
- QM: 체스 핵심 규칙, 예외 상황, 픽스처 및 Perft 벤치마크 테스트 검증
- TL: 순수 Java 도메인 모델 설계의 독립성, 불변성 및 아키텍처 정합성 확인

## 검수 범위

CP-03의 순수 Java 기반 체스 도메인 및 규칙 엔진을 검수한다.

- [x] 불변 도메인 모델 구현 (`Position`, `Piece`, `Move`, `CastlingRights`, `Board`, `GameState`)
- [x] FEN (Forsyth-Edwards Notation) 파서 및 직렬화 유틸리티 (`FenParser`)
- [x] 체스 규칙 엔진 및 수 생성기 (`MoveGenerator`)
  - [x] 6종 기물별 기본 이동/공격/차단 규칙
  - [x] 폰 특수 규칙: 1칸 전진, 초기 2칸 전진, 대각선 포획, 앙파상(En passant), 승급(Promotion Q/R/B/N)
  - [x] 킹 특수 규칙: 캐슬링(킹사이드/퀸사이드), 통과 칸 공격 방지, 체크 상태 캐슬링 불가
  - [x] 체크(Check), 체크메이트(Checkmate), 스테일메이트(Stalemate) 판정
  - [x] 킹 노출 방지(절대 핀된 기물 이동 차단)
- [x] 대국 상태 관리 및 특수 무승부 규칙 (`GameState`)
  - [x] 기물 부족으로 인한 무승부 (Insufficient Material: K vs K, K+B vs K, K+N vs K, K+B vs K+B)
  - [x] 3회 반복 무승부 청구 및 5회 반복 자동 무승부 (Repetition detection)
  - [x] 50수 규칙 청구 및 75수 자동 무승부 (50-move / 75-move rule)
  - [x] 기권(Resign) 및 시간초과(Timeout) 상태 전이
- [x] 공식 체스 엔진 벤치마크 Perft(Performance Test) 계산기 및 단위 테스트 (`PerftCalculator`, `PerftTest`)
- [x] 필수 체스 규칙 픽스처 테스트 (`ChessRuleEdgeCasesTest`)
- [x] 프레임워크(WebFlux, JPA, HTTP)에 의존하지 않는 순수 도메인 모듈 구조

### 2. TDD 테스트 스위트 (총 55개 테스트 통과)
1. `PositionTest`: 좌표 유효성 검사, 대수 표기 파싱, 오프셋 계산 (8개 테스트)
2. `PieceTest`: FEN 문자 상호 변환 및 타입 검증 (13개 테스트)
3. `MoveTest`: UCI 표기 파싱/직렬화 및 유효성 검증 (3개 테스트)
4. `CastlingRightsTest`: FEN 파싱/직렬화 및 이동/포획에 따른 권리 상실 검증 (3개 테스트)
5. `BoardTest`: 초기 배치, FEN 복원, 불변 객체 조작 (3개 테스트)
6. `MoveGeneratorTest`: 기물별 수 생성, 폰 승급, 앙파상, 캐슬링 제약, 핀(Pin) (6개 테스트)
7. `GameStateTest`: 대국 진행, 스콜라 메이트, 스테일메이트, 기물 부족 무승부, 기권/시간초과, 3회 반복 (7개 테스트)
8. `PerftTest`:
   - 초기 포지션 (Depth 1~4: 20, 400, 8,902, 197,281 노드 일치)
   - Position 2 (Kiwipete) (Depth 1~3: 48, 2,039, 97,862 노드 일치)
   - Position 3 (Depth 1~3: 14, 191, 2,812 노드 일치)
   - Position 4 (Depth 1~3: 38, 1,741, 64,027 노드 일치)
   - Position 5 (Depth 1~3: 44, 1,486, 62,379 노드 일치)
9. `ChessRuleEdgeCasesTest`:
   - Castling-through-check 픽스처
   - En passant expiry (1수 직후 만료) 픽스처
   - Promotion with check 픽스처
   - Stalemate 픽스처
   - Checkmate (Fool's mate) 픽스처
