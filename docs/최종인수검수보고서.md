## 2. 라이브 서버 인수 테스팅 (Acceptance Testing) 수행 결과

- **테스트 환경**: Java 25.0.4, Spring Boot 4.1.1, Netty Server Port 8080 (Active Profile: `local`)
- **실행 스텁**: `acceptance_stub_test.js` 및 `FinalAcceptanceIntegrationTest.java`

### 📋 인수 시나리오별 검증 내역
1. **[시나리오 1] 시스템 상태 및 헬스체크 (`GET /actuator/health`)**
   - **결과**: `{"status": "UP"}` (Database: H2/Postgres 정상 연동 확인)
2. **[시나리오 2] 2인 대전(PVP) 전체 라이프사이클**
   - 대국 생성 (`POST /api/v1/games`) ➔ `game-d7bd89f5` 발급 (`WAITING_FOR_OPPONENT`)
   - 상대방 참가 (`POST /api/v1/games/{id}/join`) ➔ 상태 `ACTIVE` 전이
   - 백 플레이어(Alice) 수 착수 (`e2 -> e4`) ➔ 기보 기록 및 턴 전환 (`BLACK`)
   - 흑 플레이어(Bob) 기권 (`POST /api/v1/games/{id}/resign`) ➔ 상태 `RESIGNED`, 결과 `WHITE_WON` 확정
3. **[시나리오 3] AI 대전(PVC, Stockfish ELO 2000+) 라이프사이클**
   - 대국 생성 즉시 `ACTIVE` 상태 시작, 흑 플레이어 `Stockfish AI` 자동 배정
   - 플레이어 착수 완료 직후 비동기 스레드 풀(`aiEngineTaskExecutor`)에서 합법 AI 수 자동 생성 및 턴 복귀 확인
4. **[시나리오 4] 보안 통제 및 불법 수 차단**
   - 제3자 비인가 사용자의 수 조작 시도 차단 확인
   - 폰 3칸 이동 등 FIDE 체스 규칙 위반 수 거부 확인

## 3. 결함 점검 및 최종 조치 사항

- **식별된 잠재 결함 및 조치 완료 내역**:
  1. *[조치 완료]* 외부 Stockfish 바이너리가 없는 환경에서도 100% 동작하도록 순수 Java Minimax Fallback 엔진 탑재.
  2. *[조치 완료]* 같은 턴 번호(moveNumber) 내에서 백/흑 순서 역전 방지를 위해 `findTopByGameIdOrderByIdDesc`로 정렬 기준 최적화.
  3. *[조치 완료]* 로컬 무설치 구동을 위한 `application-local.properties` 프로파일 및 `runtimeOnly 'com.h2database:h2'` 의존성 보강.
