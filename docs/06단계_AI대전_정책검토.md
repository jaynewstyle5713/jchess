# AI 대전 모드(PVC) 및 ELO 2000+ 엔진 연동 정책 점검 보고서

본 문서는 `docs/chess-game-rules.md`에 새롭게 추가된 **AI 대전 모드(Player vs Computer, PVC)** 및 **ELO 2000 수준 UCI 엔진 연동** 요구사항에 대해 역할별 페르소나(PM, TL, QM, SM, UX) 관점에서 종합 검토하고 프로젝트 계획, 아키텍처 및 안전 대책을 수립한 점검 결과이다.

| **TL (테크니컬 리더)** | UCI 프로토콜 통합 아키텍처, 비동기 스레드 풀, 서버 블로킹 방지 및 프로세스 생명주기 | **승인** |

## 2. 페르소나별 상세 검토 결과

### 2.1 PM (프로젝트 매니저) 관점
- **요구사항 정의**: 사용자가 매칭 대기 시간 없이 즉시 1인 플레이를 즐길 수 있는 PVC 모드를 지원하며, 체스 중상급자(Expert/CM 레벨, ELO 2000) 수준의 만족감을 제공한다.
- **범위 조정**: 기존 MVP 제외 항목이었던 "AI 상대"를 Phase 4~4.5 범위로 승격하여 프론트엔드 대국 UI(Phase 4)와 백엔드 엔진 어댑터(Phase 4.5)로 연계 구현한다.
- **의사결정**:
  - 기본 PVP 대국 구조(도메인 규칙 엔진, WebSocket 프로토콜)를 100% 재사용하여 시스템 복잡도를 최소화한다.
  - 별도 계정 로그인 없이도 AI와 대국을 즉시 시작할 수 있어 사용자 온보딩 경험이 대폭 향상된다.

### 2.2 TL (테크니컬 리더) 관점
- **아키텍처 설계**:
  - **프로토콜 표준**: UCI(Universal Chess Interface) 표준 프로토콜을 사용하는 Stockfish 바이너리를 `ProcessBuilder`로 제어한다.
  - **비동기 격리**: WebFlux 이벤트 루프와 HTTP 스레드가 블로킹되지 않도록 전용 `aiEngineTaskExecutor`(ThreadPool: 4~8 Threads)를 구성하고 `CompletableFuture` 기반으로 비동기 호출한다.
  - **엔진 튜닝**: `setoption name UCI_LimitStrength value true`, `setoption name UCI_Elo value 2000` (또는 Move Time / Depth 12~15)을 적용하여 일관된 2000 ELO 수준을 유지한다.
  - **단일 수 파이프라인**: AI가 도출한 Best Move는 일반 사용자와 동일하게 `GameService.playMove()`를 경유하도록 설계하여 도메인 불변식을 100% 보장한다.

### 2.3 QM (품질 관리자) 관점
- **테스트 시나리오 수립**:
  1. **정상 흐름**: 플레이어 착수 -> AI 비동기 트리거 -> 1~3초 내 합법 수 수신 -> 보드 갱신 및 WebSocket 브로드캐스트.
  2. **체크/프로모션/엔드게임**: AI가 체크 상황 방어, 프로모션 선택(Q/R/B/N), 엔드게임 무승부(50-move, 3회 반복)를 정확히 인지하는지 검증.
  3. **예외 및 장애 복구**: AI 엔진 프로세스 비정상 종료(SIGKILL) 시 자동 재시작 및 Fallback 합법 수 처리, Timeout(5초 초과) 시 예외 처리 검증.
  4. **성능 검증**: 동시 10개 이상의 PVC 대국 진행 시 CPU/스레드 사용률 및 응답 지연 측정.

### 2.4 SM (보안 관리자) 관점
- **보안 통제 대책**:
  - **커맨드 인젝션 차단**: UCI 명령어 파라미터는 엄격하게 화이트리스트 검증된 FEN/Algebraic 문자열만 사용하며, 셸(cmd/bash) 인터프리터를 거치지 않고 직접 바이너리 인자를 전달한다.
  - **프로세스 격리 및 리소스 제한**: 엔진 프로세스의 최대 실행 시간(Timeout 5초)과 최대 생성 프로세스 풀 개수를 제한하여 시스템 DoS(Denial of Service)를 방지한다.
  - **클라이언트 변조 방지**: 클라이언트가 AI의 수를 직접 지정하거나 위조할 수 없도록 서버 권위형으로만 AI 수를 주입한다.

### 2.5 UX/UDI (사용자 경험 디자이너) 관점
- **화면 및 상호작용 피드백**:
  - **대국 생성 모달**: 대국 방식 선택지(2인 대전 PVP / AI 대전 PVC) 및 AI 프로필(Stockfish AI - ELO 2000) 배지 노출.
  - **실시간 사고 인디케이터**: 플레이어 착수 직후 상대 플레이어 영역에 "AI가 최선의 수를 생각하고 있습니다..." 스피너 및 펄스 효과 애니메이션 노출.
  - **자연스러운 턴 전환**: AI의 착수가 너무 즉각적(0.01초)으로 이루어지면 사용자가 당황할 수 있으므로, 최소 체감 생각 시간(약 500ms~1500ms)을 부여하여 인간적인 대국 리듬 제공.
